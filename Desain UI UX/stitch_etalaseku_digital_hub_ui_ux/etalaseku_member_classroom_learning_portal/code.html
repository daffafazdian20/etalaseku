Modul 03: Membangun UI SPA Responsif dengan Tailwind CSS di Google Apps Script

schedule 18 Menit

Ikhtisar Pelajaran

Pada modul ini, kita menghubungkan script template HTML modern ke dalam Google Apps Script (GAS) menggunakan helper function include(). Kita mengeksekusi integrasi Tailwind CSS CDN v3 yang ringan, memfasilitasi Single Page Application (SPA) responsif tanpa perlu kompilasi Node.js eksternal yang rumit.

Index.html — Google Apps Script Template 
<!DOCTYPE html>
<html>
  <head>
    <base target="_top">
    <!-- Tailwind CSS via fast script CDN -->
    <script src="https://cdn.tailwindcss.com"></script>
    <?!= include('Styles'); ?>
  </head>
  <body class="bg-slate-50 text-slate-900">
    <div id="app" class="max-w-4xl mx-auto p-6">
      <!-- SPA Dynamic View Container -->
      <h1 class="text-2xl font-bold text-midnight-indigo">Halo EtalaseKu Apps Script!</h1>
    </div>
    <?!= include('JavaScript'); ?>
  </body>
</html>

Gunakan HtmlService.createTemplateFromFile():

Memungkinkan modularitas file terpisah untuk HTML, stylesheet, dan logic client JavaScript tanpa batasan iframe.

Memanfaatkan browser compile Tailwind secara instan langsung di Google Apps Script tanpa Node.js/Webpack build pipeline.

check_circle

Menerapkan hash routing (#dashboard, #checkout) untuk mencegah refresh halaman browser saat navigasi aplikasi.
